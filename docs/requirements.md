---

## 1. 目标

做一个「HTML 格式 PPT」制作 skill，满足：

- 设计为 16:9 的 HTML 幻灯片
- 支持演示、翻页、总览、全屏和 PDF 导出

---

## 2. 输入与内容

### 2.1 输入

- [ ] 可选：主题色/PPT模板 / 品牌规范 / 指定风格参考
- [ ] 可选：输出语言（默认中文）

### 2.2 内容提取

- [ ] 允许重排与拆分句子，但不能改变含义
- [ ] 不编造事实、数据、结论
- [ ] 示意性 UI 数据必须标注「示意」或「UI Preview」

---

## 3. 页面规格

- [ ] 16:9，一页 PPT 对应一页 HTML 幻灯片
- [ ] 基准尺寸 1280 × 720，按窗口等比缩放
- [ ] 单页显示
- [ ] 页面居中，窗口变化时自动重新适配
- [ ] 单个 HTML 文件交付，双击即可打开
- [ ] 不依赖外部资源（字体使用系统字体栈）

---

## 4. 视觉与排版

### 4.1 主题色

- [ ] 主题色必须与要求 一致
- [ ] 深色页只作为节奏变化，不宜超过总页数的 1/3

### 4.2 设计原则

- [ ] 编辑设计 / 杂志跨页风格
- [ ] 数字使用衬线字体（Georgia 等），正文使用无衬线
- [ ] 每页版式要有变化，避免全篇同一种卡片网格
- [ ] 可用 hover 微交互，但不能影响阅读和性能
- [ ] 视觉层级清晰：一页只允许一个视觉重心

---

## 5. 演示交互

### 5.1 翻页

- [ ] 单击页面任意处 → 下一页
- [ ] 滚轮下滑 → 下一页；上滑 → 上一页
- [ ] 滚轮防抖，一次手势只翻一页
- [ ] 键盘：`← → ↑ ↓`、`空格`、`PageUp / PageDown`
- [ ] 键盘：`Home / End` 跳首尾
- [ ] 触屏左右滑动翻页
- [ ] 触屏滑动后短时间内不得被 click 二次触发

### 5.2 控件

- [ ] 左右圆形箭头按钮
- [ ] 底部圆点导航 + 页码 
- [ ] 右上角全屏按钮，`F` 快捷键
- [ ] 右上角「所有页面」按钮，`O` 快捷键
- [ ] 控件不能遮挡正文内容

### 5.3 总览模式

- [ ] 缩略图网格展示全部页面
- [ ] 根据屏幕自动 3 / 2 / 1 列
- [ ] 点击缩略图进入对应页
- [ ] `O` / `Esc` 返回当前页
- [ ] 总览时隐藏翻页箭头、圆点、页码
- [ ] 总览时滚轮用于滚动缩略图，不触发翻页
- [ ] 点击缩略图不得触发二次翻页

### 5.4 缩略图侧栏（非演讲者模式）

> 演讲者模式 = 全屏演示；非演讲者模式 = 普通窗口浏览。

- [ ] 普通窗口下，页面左侧固定 1 列 PPT 缩略图
- [ ] 缩略图为当前页面的真实渲染，不使用占位图
- [ ] 当前页缩略图高亮
- [ ] 鼠标悬浮缩略图时，在右侧弹出该页的放大预览
- [ ] 点击缩略图直接跳转到对应页
- [ ] 全屏（演讲者模式）时隐藏侧栏和悬浮预览
- [ ] 总览模式下隐藏侧栏
- [ ] 打印时隐藏侧栏和悬浮预览
- [ ] 在侧栏上滚动滚轮只滚动缩略图，不触发翻页
- [ ] 小窗口（宽度 < 980px）自动隐藏侧栏

---

## 6. 性能

- [ ] 切页跟手，不卡顿
- [ ] 只渲染当前页
- [ ] 支持 `prefers-reduced-motion`，自动关闭动画

---

## 7. 导出

- [ ] 浏览器打印可导出 PDF
- [ ] 页面尺寸 `13.333in × 7.5in`
- [ ] 一页幻灯片对应一张 PDF 页
- [ ] 打印时隐藏所有导航 / 总览控件
- [ ] 打印时强制显示全部页面，取消缩放 transform

---

## 8. 工作流

- [ ] Step 1：输出「标题 + 内容」Markdown
- [ ] Step 2：确定视觉方向与版式节奏
- [ ] Step 3：生成单文件 HTML
- [ ] Step 4：交付说明（文件路径、页数、操作方式）
- [ ] 生成后直接交付，由用户验收，不需要反复截图验证

---

## 9. 交付物

- [ ] `slides-XX-XX.html`：单文件 HTML 演示
- [ ] `slides-XX-XX.md`：标题 + 内容文本
- [ ] 可选：PDF 导出

---

## 10. 验收清单

- [ ] 所有指定页面内容完整、无改写、无编造
- [ ] 每页版式不同
- [ ] 单页显示，无纵向堆叠
- [ ] 单击 / 滚轮 / 键盘 / 触屏均可翻页
- [ ] 总览可打开、可跳转、可返回
- [ ] 非演讲者模式有缩略图侧栏，可悬浮放大、点击跳转
- [ ] 切页不卡顿
- [ ] 打印为 6 页 16:9 PDF
- [ ] 全屏可用
- [ ] 不同窗口尺寸下不变形、不溢出
